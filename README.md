# Portfolio

Files:
- index.html: page structure (content)
- style.css: appearance (colors, layout)

Deploy to GitHub Pages:
1. Create a repo named yourusername.github.io on GitHub.
2. Upload index.html and style.css to the repo's root folder.
3. Settings > Pages > Source: Deploy from branch, main, / (root).
4. Visit https://yourusername.github.io after about a minute.
